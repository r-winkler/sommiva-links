# sommiva.app

Invitation links of the Sommiva app. Generated by `tool/website/build_link_site.py` in the app repository; do not
edit by hand.

- `404.html`: page for `/join/<token>` when the app is not installed (GitHub Pages serves it for unknown paths)
- `.well-known/`: verification files for Android App Links and iOS Universal Links
- `index.html`: leads to https://sommiva.com/
